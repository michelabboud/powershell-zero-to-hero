# How to Use This Answer Booklet

This booklet contains verified solutions for every exercise in the
**PowerShell: Zero to Hero** training guide.

## Organization

Answers mirror the chapter numbering:
- `Ch-01, Ex-1` = Chapter 1, Exercise 1
- Labels match between the main guide and this booklet

## Before You Look

Try the exercise yourself first. Struggle is where learning happens.
If you're stuck for more than 10 minutes, check the answer -- but read
the "What to notice" section to understand *why* it works.

## Verification

Every solution in this booklet has been tested with Pester 5.5+ on
PowerShell 7.4+ (Windows and Linux). Run the tests yourself:

```powershell
pwsh ./tests/run-all.ps1
```

## Difficulty Labels

- **(Simple)** -- Guided, heavily commented
- **(Normal)** -- Realistic, moderate comments
- **(Advanced)** -- Minimal guidance, production-style
- **(Extreme)** -- Constraint-based, battle-tested edge cases
