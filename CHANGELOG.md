# Changelog

All notable changes to this guide are documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project uses semantic version tags for published guide editions.

## [1.1.0] - 2026-08-01

### Added

- A self-contained public source repository under the MIT License.
- Reproducible PDF and HTML builds for the main guide and answer booklet.
- Standalone repository validation, Python contract tests, and Pester answer
  tests.
- Pinned GitHub Actions validation, all-format builds, checksums, and tag-based
  GitHub Releases.
- A primary-source content audit covering all chapters and appendices.

### Changed

- Updated examples and guidance for current PowerShell, Pester, and supported
  cross-platform behavior.
- Made all maintained build inputs repository-relative and independent.

### Preserved

- The historical root PDF remains byte-identical to the captured source and is
  not presented as a regenerated release artifact.
